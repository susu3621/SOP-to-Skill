<h2>快速开始</h2>
<ol>
<li>先浏览首页，确认这个产品解决的问题和适用场景。</li>

<section class="docs-home-section">
<h2>你会在产品里做什么</h2>
<ul>
<li>选择基础技能，并完成环境检测或连通测试。</li>
<li>按岗位填写用例、信息来源和规则。</li>
<li>预览将要新增、移除或保持不变的 Skill 集合。</li>
<li>把结果同步到 Codex、Claude Code 或 WorkBuddy。</li>
</ul>
</section>

<section class="docs-home-section docs-home-section--wide">
<h2>使用流程</h2>
<div class="docs-flow-list">
<article>
<span>01</span>
<h3>准备基础环境</h3>
<p>先把 Jira、Confluence、文档模板、Linux、Gerrit 这类基础能力接通，确保后续配置可以落地。</p>
</article>
<article>
<span>02</span>
<h3>组织岗位工作</h3>
<p>把岗位目标、使用场景、信息来源和规则整理成可复用的工作结构。</p>
</article>
<article>
<span>03</span>
<h3>生成并安装 Skill</h3>
<p>系统会把配置结果产出成可安装内容，并按目标 AI 工具提供同步入口。</p>
</article>
<article>
<span>04</span>
<h3>在真实任务中迭代</h3>
<p>用真实工作暴露缺口，再把新的经验回灌到 Skill，持续提高可复用性。</p>
</article>
</div>
</section>
