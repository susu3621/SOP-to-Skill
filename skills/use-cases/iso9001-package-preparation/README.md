# ISO9001 Internal Audit Template Assets

This directory owns the repository-side template assets for the `iso9001-package-preparation` business use case.

- `templates/iso9001-internal-audit-checklist.xlsx` is the default Excel checklist template for ISO9001 internal-audit work.
- The checklist clause structure is the reference structure for the evidence-package zip.
- When evidence comes from pages, export those pages into files before placing them into the matching clause directory.

New business workflows that need repository-owned templates should follow the same layout:

```text
skills/use-cases/<use-case-directory>/
```
